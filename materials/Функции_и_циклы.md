# Функции и циклы в JavaScript

В этом блоке мы связываем уже знакомые конструкции JavaScript в более крупные фрагменты программы. **Функции** позволяют дать участку кода имя и использовать его повторно, а **циклы** выполняют одно действие несколько раз.

## 1. Зачем нужны функции

Без функции одинаковые действия приходится повторять вручную:

```js
const first = 5 + 7;
const second = 10 + 20;
const third = 3 + 4;
```

Если действие имеет понятный смысл, его удобнее оформить как функцию:

```js
function sum(a, b) {
  return a + b;
}

console.log(sum(5, 7));
console.log(sum(10, 20));
console.log(sum(3, 4));
```

Функция состоит из имени, параметров и тела. Код внутри тела выполняется только после вызова функции.

```js
function greet(name) {
  console.log(`Привет, ${name}!`);
}

greet('Иван');
```

## 2. Параметры и аргументы

В объявлении функции записываются **параметры** — имена значений, которые функция ожидает получить:

```js
function multiply(a, b) {
  return a * b;
}
```

При вызове передаются **аргументы**:

```js
multiply(4, 5);
```

Здесь `a` и `b` — параметры, а `4` и `5` — аргументы конкретного вызова.

Параметру можно задать значение по умолчанию:

```js
function power(base, exponent = 2) {
  return base ** exponent;
}

console.log(power(5));    // 25
console.log(power(5, 3)); // 125
```

## 3. `return`

`return` завершает выполнение функции и возвращает результат в место вызова.

```js
function getMax(a, b) {
  if (a > b) {
    return a;
  }

  return b;
}

const max = getMax(10, 7);
console.log(max);
```

После выполненного `return` код ниже него в этой функции уже не выполняется.

```js
function checkAge(age) {
  if (age < 0) {
    return 'Ошибка';
  }

  return age >= 18 ? 'Совершеннолетний' : 'Несовершеннолетний';
}
```

Если функция ничего явно не возвращает, результатом вызова будет `undefined`.

## 4. Способы записи функций

### Function Declaration

```js
function sum(a, b) {
  return a + b;
}
```

### Function Expression

Функцию можно сохранить в переменную:

```js
const sum = function (a, b) {
  return a + b;
};
```

### Стрелочная функция

```js
const sum = (a, b) => {
  return a + b;
};
```

Для короткого выражения запись можно сократить:

```js
const square = value => value ** 2;
```

На текущем этапе важнее уверенно понимать параметры, вызов и `return`. Различия между формами записи функций будем углублять позже.

## 5. Область видимости

Переменная, созданная внутри функции через `let` или `const`, обычно доступна только внутри этой функции.

```js
function calculate() {
  const result = 10 + 20;
  console.log(result);
}

calculate();
// console.log(result); // ReferenceError
```

Это позволяет функциям хранить промежуточные значения, не засоряя внешний код.

# Циклы

## 6. Цикл `for`

`for` удобен, когда заранее понятно, сколько раз нужно повторить действие.

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

У цикла три части:

```text
for (начальное действие; условие продолжения; действие после итерации)
```

Например, вывести числа от 1 до 10:

```js
for (let i = 1; i <= 10; i++) {
  console.log(i);
}
```

Посчитать сумму:

```js
let sum = 0;

for (let i = 1; i <= 10; i++) {
  sum += i;
}

console.log(sum); // 55
```

## 7. Цикл `while`

`while` выполняет тело, пока условие остаётся истинным.

```js
let value = 1;

while (value <= 5) {
  console.log(value);
  value++;
}
```

`while` удобен, когда количество повторений заранее не так очевидно, но есть понятное условие остановки.

Важно следить, чтобы состояние внутри цикла менялось. Иначе можно получить бесконечный цикл.

## 8. `do...while`

В `do...while` тело выполняется **как минимум один раз**, а условие проверяется после итерации.

```js
let value = 1;

do {
  console.log(value);
  value++;
} while (value <= 5);
```

Главное отличие:

- `while` сначала проверяет условие;
- `do...while` сначала выполняет тело.

## 9. `break`

`break` полностью завершает ближайший цикл.

```js
for (let i = 1; i <= 100; i++) {
  if (i % 17 === 0) {
    console.log(`Первое подходящее число: ${i}`);
    break;
  }
}
```

Такой приём нужен, когда дальнейший перебор уже не имеет смысла.

## 10. `continue`

`continue` пропускает остаток текущей итерации и начинает следующую.

```js
for (let i = 1; i <= 10; i++) {
  if (i % 2 !== 0) {
    continue;
  }

  console.log(i);
}
```

В консоль попадут только чётные числа.

## 11. Функция и цикл вместе

На практике цикл часто находится внутри функции. Функция получает исходные данные, цикл выполняет повторяющееся действие, а `return` возвращает результат.

```js
function sumRange(from, to) {
  let sum = 0;

  for (let value = from; value <= to; value++) {
    sum += value;
  }

  return sum;
}

console.log(sumRange(1, 5)); // 15
```

Ещё один пример — возведение в степень без оператора `**`:

```js
function power(base, exponent) {
  let result = 1;

  for (let i = 0; i < exponent; i++) {
    result *= base;
  }

  return result;
}

console.log(power(2, 5)); // 32
```

## 12. На что обращать внимание

1. У цикла должно быть условие завершения.
2. Счётчик не обязан называться `i`, но для небольших циклов это общепринятое имя.
3. Не изменяйте счётчик случайно внутри тела цикла без необходимости.
4. Если нужен итог вычисления, создайте переменную до цикла и изменяйте её внутри.
5. В функции возвращайте результат через `return`, а не только выводите его через `console.log()`.
6. `break` завершает цикл, `continue` пропускает только текущую итерацию.

## 13. Что пока не требуется

В старых примерах можно встретить перебор массивов через `for...of`, `for...in`, `forEach()`, а также `map()`, `filter()` и `reduce()`. Эти конструкции полезны, но относятся уже к следующему блоку про массивы. Сейчас достаточно обычных `for`, `while`, `do...while`, `break`, `continue` и функций.
