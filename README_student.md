## Тема

Функции и циклы в JavaScript.

## Запуск тестов

```bash
node tests.js
```

## Что нужно заполнить

Откройте `student-template.js` и заполните участки `TODO`.

Не изменяйте:

- названия функций;
- список параметров функций;
- блок `module.exports` в конце файла.

В этой работе основная логика должна находиться **внутри функций**. Для повторяющихся действий используйте циклы. Условия задач, ограничения и примеры находятся в документе `Практическая_работа_3.docx`.

## Сдача

В репозитории должны находиться:

- заполненный `student-template.js`;
- README с краткой инструкцией запуска;
- при выполнении браузерного варианта — HTML/JS-файлы с вводом через `prompt()` и выводом через `alert()` или `console.log()`.

Перед отправкой обязательно выполните:

```bash
node tests.js
```

Все группы тестов должны завершиться успешно.
